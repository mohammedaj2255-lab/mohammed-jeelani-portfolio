- `styles.css` — shared luxury/futuristic design system and responsive layouts
- `app.js` — scroll reveals, animated metrics, mobile menu, particles, rotating role text, and subtle internal-page transitions
- Respects `prefers-reduced-motion` and includes a keyboard skip link.

## Publish with GitHub Pages
1. Download and extract the ZIP.
2. Open your public GitHub repository.
3. Upload **all contents inside this folder** into the repository root, preserving the `assets` folder.
4. Open **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to finish deploying; `index.html` is the homepage.

Keep all six HTML pages, `styles.css`, `app.js`, and `assets/profile.png` together. Google Fonts are optional external fonts; system fallbacks are defined.
